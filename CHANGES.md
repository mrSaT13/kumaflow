# KumaFlow Changelog

Все изменения в проекте KumaFlow.


## [1.13.1] - 2026-10-20

### 🌊 Волна и мозг
- Сброс сида радио гасит его и на сервере (`DELETE /api/wave/seed`): раньше сброс был только локальным, а мозг продолжал держать сид и рулить волной — стиль «В стиле: …» залипал
- Обычный запуск волны и кнопка «×» на главной сбрасывают сид одинаково (раньше — по-разному)

### 🛠 Прочее
- Обновлённая сборка 1.13.0 (WebGL-плазма в «Моей волне», тихий автостарт пульта) вошла в репозиторий


## [1.13.0] - 2026-10-19

### 🌊 «Моя волна» — третий вид (WebGL-плазма)
- Живой шейдер вместо статичной капли: domain-warped плазма, дыхание, цикл форм шар→звезда→петля→капля, тонкие белые петли-разряды, световые shafts-лучи
- Лучи — единственный реактивный слой: длина/прямизна от ударов (AnalyserNode), петли и поле — спокойный эмбиент
- Настроение по жанру для шейдера (огонь с языками пламени и углями для рока/метала, кольца для электроники, блёстки для попа), цвет следует за обложкой трека без отставания, кроссфейд видов 700мс
- CSS-фолбэк без WebGL тоже дышит от музыки

### 🎛 Remote Control
- Тихий автостарт пульта при запуске приложения (раньше сервер поднимался только при открытии настроек); ретрай автостарта в main-процессе


## [1.12.0] - 2026-10-14

Крупное обновление после v1.6.6: новая «Моя волна», переработанные Библиотека и сайдбар, закреплённые артисты, умная модалка исполнителей.

### 🌊 «Моя волна» — новый hero
- Живая капля из 3 цветных слоёв: цвет берётся из обложки трека → жанр → дефолт, плавный переезд ~0.7с
- 10 эффектов настроений по жанрам (огонь, warp, mist, sparkle, bounce…) + лучи вместо полосок, тумблеры в Настройки → Внешний вид
- Кроссфейд настроений 750мс при смене трека

### 📚 Библиотека и сайдбар
- Новая страница «Библиотека»: разделы-навигация (исполнители/треки/альбомы — вся коллекция, радио, книги, локальная, «Для вас»), «Мне нравится», любимые исполнители/альбомы, плейлисты с красивым переходом «Все плейлисты», дизлайки
- Сайдбар по умолчанию чистый: разделы Библиотеки, Плейлисты и «Для вас» скрыты, всё доступно из /library; включается в Настройки → Внешний вид → Сайдбар (там же drag-and-drop порядок)
- Пустые заголовки «Библиотека»/«Плейлисты» больше не висят — секции появляются только когда тумблер включён
- Кэш данных библиотеки: мгновенный показ + автообновление в фоне
- Закреплённые артисты (пин, до 20) с круглыми аватарами в сайдбаре — круги больше не сплющиваются

### 🎤 Исполнители
- Модалка «Исполнители» как в мобилке: фото подтягиваются поиском по имени (чинит склейки вида «A/B»), тап сразу ведёт на страницу артиста
- Дейли-микс мозга сохраняется как «KumaFlow Mix»

### 🎛 Remote Control и обновления (вошло из 1.7.0–1.7.3)
- PIN-код для страницы управления задаётся в плеере, QR/ссылка не пропадают, выбор сетевого адреса включая VPN, страница Remote есть в собранной версии, PWA
- Синхрон с мозгом без визита в настройки (user_id при старте), handoff с позицией, «Продолжить с …» в ховере «Моей волны»
- Секция «О программе»: версия, что нового, проверка обновлений через GitHub Releases

### 🐛 Исправления
- Remote больше не просит пароль Navidrome (берётся из текущего аккаунта), очередь на Remote-странице не перекрывает кнопки


## [1.7.3] - 2026-10-06

### 🐛 Исправления
- **Синхрон с мозгом больше не зависит от открытых настроек** — `user_id` мозга поднимается автоматически при старте (`brain-bootstrap.ts`), а не только кнопкой «Синхронизировать сейчас». Раньше все вызовы мозга выходили по `if (!userId) return`, поэтому живая очередь, события, общие пилюли волны и handoff молчали до визита в настройки
- **Мозг поднимается и сам** — включил/сменил URL или токен, сменил аккаунт Navidrome: `user_id` перепривязывается сразу (иначе publish/sync уходили в 404 на новый сервер)
- **Автосинк вкусов не «съедает» интервал** — если мозг не поднялся (нет логина/токена), следующая попытка через минуту, а не через полчаса; первый прогон теперь ~20с вместо ~90с
- **Handoff больше не затирается** — publish из `App.tsx` шёл без `position_sec`, а сервер заменяет слот целиком: телефон/веб теряли секунду и «Продолжить» стартовало с нуля. Позиция теперь всегда берётся из audio-элемента

### ✨ Новые функции
- **«Продолжить с …» в ховере карточки «Моя волна»** — забирает живую очередь с телефона/другого ПК и стартует с той же секунды. Список устройств из мозга, выбор слота, ток, позиция и хвост очереди. Панель раскрывается на ховере и не занимает место в свёрнутом виде
- **Типизация `waveResume()` по фактическому ответу сервера** (`track`, `position_sec`, `stale`, `devices[]`) + поднятие `user_id` на лету
